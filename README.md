## 🛠️ Getting Started & Running Locally

To explore the landing pages locally:

### Option 1: Live Server / Any Static File Server
```bash
# Clone the repository
git clone https://github.com/siddharthkmaharana/landing_page_gallery.git
cd landing-page_gallery

# Serve locally using npx serve or python
npx serve .
# or
python -m http.server 8000
```
Then open:
- `http://localhost:8000/landing-page-01/` in your browser.

### Option 2: Direct Browser Launch
Simply navigate into `landing-page-01/` and double-click `index.html`.

## 🌐 GitHub Pages Deployment

To host this gallery directly via GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/siddharthkmaharana/landing_page_gallery`
2. Navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` (root) and click **Save**.
4. Access `landing-page-01` at:
   `https://siddharthkmaharana.github.io/landing_page_gallery/landing-page-01/`
